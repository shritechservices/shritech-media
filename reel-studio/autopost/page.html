Meta connection (Facebook + Instagram)

These keys are saved securely in your private database. The token is never shown again after saving.

How to get these keys (step by step)
  1. Make sure your Instagram is a Business or Creator account and is linked to your Facebook Page (Instagram app → Settings → Account type / Linked accounts).
  2. Go to developers.facebook.com/apps → Create app → choose the Business type (or the use case "Manage everything on your Page" + "Manage messaging & content on Instagram").
  3. Open Graph API Explorer, pick your app, then add permissions: pages_show_list, pages_read_engagement, pages_manage_posts, instagram_basic, instagram_content_publish, business_management → Generate Access Token and allow your Page + Instagram.
  4. Make it long-lived: open the Access Token Debugger, paste the token → Extend Access Token.
  5. Back in Graph Explorer, with the long-lived token, run me/accounts. Copy your Page's id (= Facebook Page ID) and its access_token (= Page Access Token, it does not expire).
  6. Run {page-id}?fields=instagram_business_account — the id shown is your Instagram Business Account ID.
  7. Paste all three here → Save → Test connection. You should see ✅ for both.
